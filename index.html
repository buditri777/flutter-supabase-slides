Apa Itu Database?

Database adalah kumpulan data terstruktur yang disimpan secara elektronik dalam sistem komputer, dikelola oleh DBMS (Database Management System).

  • Persisten — data tetap ada meski aplikasi ditutup
  • Terstruktur — disimpan dalam tabel/dokumen yang konsisten
  • Multi-user — banyak user bisa akses bersamaan
  • Reliable — backup, transaksi, integritas data
04

Jenis-Jenis Database

SQL / Relational

PostgreSQL · MySQL · SQLite

  • Data dalam tabel (rows & columns)
  • Skema kaku, terdefinisi
  • Query pakai SQL standar
  • ACID compliant
  • Cocok untuk: data transaksional, relasi kompleks

NoSQL / Non-Relational

MongoDB · Firestore · Redis

  • Data dalam dokumen/key-value/graph
  • Skema fleksibel
  • Query via API/method
  • Eventual consistency
  • Cocok untuk: data tidak terstruktur, scale horizontal
💡 Supabase pakai PostgreSQL — database relational paling populer dengan fitur lengkap (JSON, full-text search, geospatial).
05

Arsitektur Flutter Framework

Flutter dibangun berlapis. Memahami arsitektur ini penting agar kita tahu di layer mana database harus diakses.

  • Framework Layer — Widget, Material, Cupertino
  • Engine Layer — Skia, Dart Runtime, Text rendering
  • Embedder Layer — Platform-specific (Android/iOS)
Database call dilakukan di Framework Layer, bukan di Widget tree langsung. Pisahkan ke service/ atau repository/.
06

Widget Tree & Aliran Data

Di Flutter, semua adalah Widget. UI berbentuk tree, dan data mengalir dari parent ke child.

Konsep Penting:

  • StatelessWidget — UI yang tidak berubah
  • StatefulWidget — UI dengan state lokal
  • setState() — trigger rebuild widget
  • FutureBuilder — untuk async data (sekali ambil)
  • StreamBuilder — untuk realtime stream

Database hasil call → di-pass ke widget → di-render.

Membuat Tabel di Supabase

SQL untuk tabel todos dengan Row Level Security:

create table todos (
  id          uuid default uuid_generate_v4() primary key,
  user_id     uuid references auth.users(id) on delete cascade,
  title       text not null,
  description text,
  completed   boolean default false,
  priority    int default 1 check (priority between 1 and 3),
  due_date    timestamptz,
  created_at  timestamptz default now(),
  updated_at  timestamptz default now()
);

-- Enable Row Level Security
alter table todos enable row level security;

-- Policy: user hanya bisa akses todo miliknya sendiri
create policy "Users can manage their own todos"
  on todos for all
  using (auth.uid() = user_id);

-- Index untuk performa query
create index todos_user_id_idx on todos(user_id);
create index todos_created_at_idx on todos(created_at desc);

CRUD: Create (Insert Data)

// services/todo_service.dart
class TodoService {
  final _client = Supabase.instance.client;

  Future<void> addTodo(String title, {String? description}) async {
    try {
      await _client.from('todos').insert({
        'title': title,
        'description': description,
        'completed': false,
        'user_id': _client.auth.currentUser!.id,
      });
    } on PostgrestException catch (e) {
      throw Exception('Gagal menambahkan todo: ${e.message}');
    }
  }
}

// Pemakaian di UI
final service = TodoService();
ElevatedButton(
  onPressed: () async {
    await service.addTodo('Belajar Flutter');
    ScaffoldMessenger.of(context).showSnackBar(
      const SnackBar(content: Text('Todo ditambahkan!')),
    );
  },
  child: const Text('Add Todo'),
);

CRUD: Read (Select Data)

Future<List<Map<String, dynamic>>> getTodos() async {
  final data = await supabase
      .from('todos')
      .select()
      .order('created_at', ascending: false);
  return data;
}

// Dengan filter
final completed = await supabase
    .from('todos')
    .select('id, title, completed')
    .eq('completed', true)
    .limit(10);

// Render dengan FutureBuilder
FutureBuilder(
  future: getTodos(),
  builder: (ctx, snapshot) {
    if (!snapshot.hasData) return const CircularProgressIndicator();
    final todos = snapshot.data!;
    return ListView.builder(
      itemCount: todos.length,
      itemBuilder: (_, i) => ListTile(title: Text(todos[i]['title'])),
    );
  },
);

CRUD: Update & Delete

Update

Future<void> toggleTodo(
  String id, bool current) async {
  await supabase
    .from('todos')
    .update({'completed': !current})
    .eq('id', id);
}

Delete

Future<void> deleteTodo(
  String id) async {
  await supabase
    .from('todos')
    .delete()
    .eq('id', id);
}

Filter Operators

.eq()equal (=)
.neq()not equal (!=)
.gt() / .lt()greater / less than
.like()pattern match (%text%)
.in_()value in list
.is_()is null / is true

Authentication: Sign Up & Sign In

// REGISTER
Future<void> signUp(String email, String password) async {
  final response = await supabase.auth.signUp(
    email: email,
    password: password,
  );
  if (response.user != null) print('Registered!');
}

// LOGIN
Future<void> signIn(String email, String password) async {
  final response = await supabase.auth.signInWithPassword(
    email: email,
    password: password,
  );
  if (response.session != null) print('Logged in!');
}

// LOGOUT
Future<void> signOut() => supabase.auth.signOut();

// LISTEN AUTH CHANGE
supabase.auth.onAuthStateChange.listen((data) {
  final session = data.session;
  if (session != null) print('User: ${session.user.email}');
});

Realtime Subscriptions

Update UI otomatis saat data berubah di database:

// Stream realtime
final stream = supabase
    .from('todos')
    .stream(primaryKey: ['id'])
    .order('created_at');

// Pakai di StreamBuilder
StreamBuilder(
  stream: stream,
  builder: (ctx, snapshot) {
    if (!snapshot.hasData) return const CircularProgressIndicator();
    final todos = snapshot.data!;
    return ListView.builder(
      itemCount: todos.length,
      itemBuilder: (_, i) => CheckboxListTile(
        title: Text(todos[i]['title']),
        value: todos[i]['completed'],
        onChanged: (v) => toggleTodo(todos[i]['id'], v!),
      ),
    );
  },
);
⚡ Realtime aktif di Supabase Dashboard → Database → Replication → toggle table.

State Management Options

Untuk aplikasi yang konek database, pilih state management yang tepat agar UI tidak berantakan.

🔥

setState()

Bawaan Flutter, hanya untuk state lokal di satu widget. Sederhana, tapi tidak scalable.

🔅

Provider

Resmi direkomendasikan Flutter team. Ringan, mudah dipelajari, cocok project kecil-menengah.

🎯

Riverpod

Penerus Provider. Compile-safe, dependency injection bawaan. Trend di 2024+.

📊

BLoC / Cubit

Berbasis stream & event. Cocok untuk app besar dengan business logic kompleks.

⚡

GetX

All-in-one (state, route, DI). Cepat dipakai tapi opini terbagi soal best practice.

🔍

Signals (Solidart)

Reactive primitives baru. Mirip React Signals/Vue Reactivity.

Saran untuk pemula: mulai dengan Provider atau Riverpod, baru pindah ke BLoC saat aplikasi makin kompleks.

Best Practices

🔒

Aktifkan RLS

Selalu enable Row Level Security supaya data tidak bisa diakses sembarangan

🔑

Pakai anon key, bukan service key

Service key punya akses penuh — JANGAN expose di client app

📊

Index pada kolom yang sering di-query

create index on todos(user_id);

⚡

Gunakan .select() spesifik

Pilih kolom yang perlu saja: .select('id, title')

🛡

Validasi input di client + server

Pakai constraint DB (NOT NULL, CHECK) untuk safety

📝

Handle error dengan baik

Try-catch PostgrestException dan AuthException

26

Kesimpulan

  • Database adalah pondasi aplikasi modern — tempat data persisten dan terstruktur.
  • Flutter mengakses database via SDK/API, tidak langsung — pisahkan ke layer service/repository.
  • Supabase menyediakan stack lengkap (DB + Auth + Storage + Realtime) tanpa perlu setup server sendiri.
  • PostgreSQL di balik Supabase memberi kekuatan SQL penuh + ekosistem matang.
  • RLS wajib aktif untuk keamanan data multi-user.
  • Clean Architecture + state management yang tepat membuat aplikasi maintainable.
  • Pendekatan BaaS mempercepat development MVP — fokus ke fitur, bukan infrastruktur.
